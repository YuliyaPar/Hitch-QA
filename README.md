# Проект: Тестирование приложения Hitch 🤝

**Роль:** QA Engineer (ручное тестирование)
**Задача:** Протестировать веб-приложение и мобильное приложение для поиска аутстаф-специалистов.

## 🛠 Что делала:
* Работала с требованиями и макетами в Figma.
* Писала тест-кейсы и чек-листы.
* Проводила тестирование форм регистрации и авторизации (веб и мобильное).
* Тестировала личный кабинет (кандидата и компании).
* Выполняла дымовое тестирование форм.
* Проводила повторное (ретест) и регрессионное тестирование.
* Делала кросс-ревью тест-кейсов.
* Тестировала новую фичу, ретест и регресс на мобильном.
* Оформляла баг-репорты в YouGile.

## 📊 Результаты:
* Проверены основные сценарии работы с личным кабинетом.
* Найдены дефекты в UI и логике работы форм.
* Проведено кросс-ревью тест-кейсов.

## 🧰 Инструменты:
YouGile, Figma, Android Studio.
